# Cinema API

Серверна частина кінотеатру на NestJS: фільми, зали, сеанси та бронювання місць.
Дані зберігаються в масивах усередині сервісів і зникають після перезапуску.

## Встановлення залежностей

```bash
npm install
```

## Змінні середовища

Створіть у корені проєкту файл `.env` (приклад — `.env.example`):

```env
PORT=3000
```

| Змінна | Опис                         | За замовчуванням |
| ------ | ---------------------------- | ---------------- |
| `PORT` | Порт, на якому слухає сервер | `3000`           |

## Запуск у режимі розробки

```bash
npm run start:dev
```

- API: http://localhost:3000
- Swagger-документація: http://localhost:3000/docs

## Перевірка роботи

Файл `requests.http` у корені містить запити до всіх маршрутів і до кожної описаної помилки.
Відкрийте його у VS Code з розширенням **REST Client** і виконуйте запити по черзі згори вниз
(перед цим перезапустіть сервер, щоб сховища були порожні).

## Структура модулів

| Модуль     | Відповідальність                                                   |
| ---------- | ------------------------------------------------------------------ |
| `films`    | CRUD фільмів                                                       |
| `halls`    | Зали та обчислення переліку місць                                  |
| `showings` | Сеанси, фільтрація розкладу, схема місць і бронювання (`bookings`) |

Модулі звертаються один до одного лише через експортовані сервіси.
`films` і `halls` перевіряють через `ShowingsService`, чи є залежні сеанси перед видаленням,
а `showings` перевіряє через `FilmsService` і `HallsService` існування фільму й залу,
тому зв'язок між ними оголошено через `forwardRef`.

Фільтр `date` у `GET /showings` порівнює дату початку сеансу в UTC.
